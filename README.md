# OBT — 보드 동아리 오늘 현황판

동아리원이 **오늘 보드를 탈 사람**, **동방에 있는 사람**, **지금 보드를 타는 사람**을 한 화면에서 확인하고 자신의 상태를 공유하는 모바일 우선 웹 앱입니다.

회원가입이나 계정 로그인 없이 동아리 명단에 등록된 이름만 입력해 가볍게 사용할 수 있습니다.

## 주요 기능

- 이름을 동아리 명단과 대조한 뒤 입장
- 상태를 등록하기 전에는 이름이 공개되지 않는 관전 모드
- `오늘 보드 탈 예정` 독립 토글
- `동방에 있음`과 `보드 타는 중` 위치 전환
- 상단 상태 버튼 또는 본인 이름 스티커의 `×`로 상태 해제
- 같은 이름을 가진 동아리원 지원
- 10초 간격 현황 자동 갱신
- KST 날짜가 바뀌면 입장과 상태를 새로 시작
- 명단과 오늘의 입장자를 관리하는 관리자 화면

## 화면 콘셉트

교실 뒤편의 **알록달록한 코르크 핀보드**를 모티프로 합니다. 상태별 메모지와 자동 생성되는 이름 스티커를 사용해 단순한 명단을 친근하고 재미있게 표현합니다.

## 상태 모델

상태는 탑승 계획과 현재 위치를 독립적으로 관리합니다.

```text
탑승 계획
- planned: true / false

현재 위치
- location: null / in_room / riding
```

따라서 `오늘 보드 탈 예정 + 동방에 있음`, `오늘 보드 탈 예정 + 보드 타는 중`처럼 계획과 위치를 동시에 표시할 수 있습니다. `동방에 있음`과 `보드 타는 중`은 서로 중복되지 않습니다.
